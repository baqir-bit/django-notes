# Django Notes

A personal notes web application built with Django as part of my journey to become a software engineer.

## Current Features

- Django project setup
- Notes application
- Note model
- SQLite database
- Django ORM
- Database migrations
- GET /notes/ endpoint returning JSON

## Tech Stack

- Python
- Django
- SQLite

## Goals

This project is being developed step by step to learn:

- Backend development
- REST APIs
- Database design
- Authentication
- CRUD operations
- Frontend integration
- Deployment
